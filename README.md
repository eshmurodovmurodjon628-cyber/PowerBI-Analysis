# PowerBI-Analysis
Dynamic HR &amp; Salary Dashboard developed in Power BI using advanced DAX (CALCULATE, SWITCH, VAR) to analyze user skills and regional distributions.

###  Project Overview
This project is a comprehensive data analysis dashboard created in **Power BI**. It focuses on visualizing employee demographics, salary distributions, and technical skill sets. 

###  Key Features & DAX Implementations
* **Dynamic Salary Categorization:** Implemented using `SWITCH(TRUE(), ...)` logic.
* **Global Metrics:** Used `CALCULATE` combined with `ALL` to calculate market share.
* **Safe Calculations:** Leveraged the `DIVIDE` function for error handling.
* **Efficient Coding:** Used `VAR` and `RETURN` blocks for clean DAX code.

###  Technologies Used
* **Power BI Desktop**
* **DAX** (Data Analysis Expressions)
